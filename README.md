# Threat Pulse — Free cybersecurity tools and exploited vulnerability alerts

**[Explore the live Threat Pulse website](https://pulse.calculatedit.com/)** · [CVE research library](https://pulse.calculatedit.com/cve/index.html) · [Free tools](https://pulse.calculatedit.com/tools.html) · [KEV triage checklist](https://pulse.calculatedit.com/kev-triage-checklist.html)

Threat Pulse helps IT teams and home users explore source-based cybersecurity alerts and practical, privacy-conscious security tools without registration. Its CISA KEV catalog data is refreshed by automated GitHub Actions. The individual CVE research pages add an evidence-based response checklist and source references; they do **not** claim that a visitor's device is vulnerable.

**This is a public educational site operated by Calculated Ventures, LLC, not an official CISA or NIST publication.**
