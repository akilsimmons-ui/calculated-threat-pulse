# CalculatedIT Threat Pulse

An independent cybersecurity intelligence publication of **Calculated Ventures, LLC** using the CalculatedIT visual identity.

The public information site is free to browse and intended to be sustained by advertising *if approved*. Advertising is not enabled and revenue is not guaranteed.

**Status:** Initial source import in progress. The repository is separate from the private CalculatedIT RMF Accelerator.

The site generator is Python 3 with no third-party runtime dependencies. The build output is the `public/` folder, deployable to Cloudflare Pages with build command `python3 build.py --fetch` and output directory `public`.

**Official intelligence:** CISA Known Exploited Vulnerabilities. The site's tools are informational only and do not constitute a security assessment.

**Operator:** Calculated Ventures, LLC, https://calculatedit.com/

No paid AI subscription or domain purchase is required to run the starter.
